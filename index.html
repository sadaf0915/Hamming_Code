How Detection & Correction Works

  • Step 1 (Syndrome Calculation): The receiver calculates parity check equations:
    S1 = mod(b1 + b3 + b5 + b7, 2)
    S2 = mod(b2 + b3 + b6 + b7, 2)
    S4 = mod(b4 + b5 + b6 + b7, 2)
  • Step 2 (Position Lookup): The binary value of syndrome (S4 S2 S1) directly indicates the 1-based index of the corrupted bit (e.g., 111 = Bit 7).
  • Step 3 (Bit Inversion): If syndrome $\neq 000$, bit at position Error Pos is flipped (0 $\rightarrow$ 1 or 1 $\rightarrow$ 0) to restore data integrity.
